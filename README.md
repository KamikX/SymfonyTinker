# Symfony Tinker IntelliJ Plugin

<!-- Plugin description -->
Supercharge your workflow, run PHP code instantly in PhpStorm/IDEA, just like with [PsySh](https://psysh.org/). No more custom ClassAliasAutoloader(autoload_psr4 or autoload_classmap) IDE provides full access to your Symfony classes—backed by autocompletion, syntax highlighting, and error checks.
